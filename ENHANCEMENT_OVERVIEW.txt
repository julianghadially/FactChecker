┌────────────────────────────────────────────────────────────────────────────────┐
│ KEY FEATURES                                                                   │
└────────────────────────────────────────────────────────────────────────────────┘

✨ Adaptive Intelligence
   • Only searches when LLM is uncertain (saves time & cost)
   • Detects 9 different uncertainty phrases
   • Configurable confidence threshold (default: 0.6)

⚡ Performance Optimized
   • 1 LLM call for confident judgments (fast path)
   • 2 LLM calls + search for uncertain claims (thorough path)
   • Estimated 15-30% search trigger rate

🔧 Highly Configurable
   • Enable/disable adaptive search
   • Adjustable confidence threshold
   • Configurable number of search results
   • Customizable scrape length

🔄 Backward Compatible
   • Existing code works without changes
   • Optional parameters with sensible defaults
   • Graceful error handling

📊 Rich Metadata
   • Track when searches are triggered
   • Compare initial vs. final confidence
   • Access raw evidence for auditing

┌────────────────────────────────────────────────────────────────────────────────┐
│ USAGE EXAMPLES                                                                 │
└────────────────────────────────────────────────────────────────────────────────┘

Basic Usage:
  judge = JudgeModule(enable_adaptive_search=True)
  result = judge.forward("The 2024 Olympics were held in Paris")
  print(f"Web search used: {result.web_search_triggered}")

Conservative (fewer searches):
  judge = JudgeModule(confidence_threshold=0.4, num_search_results=2)

Aggressive (more searches):
  judge = JudgeModule(confidence_threshold=0.8, num_search_results=5)

Disabled (original behavior):
  judge = JudgeModule(enable_adaptive_search=False)
