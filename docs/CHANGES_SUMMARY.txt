HYBRID JUDGE MODULE - IMPLEMENTATION COMPLETE ✅
================================================================================

PROBLEM ADDRESSED:
  Recent temporal claims (December 2025 events) cannot be verified from LLM
  training data alone, but the system wasn't intelligently routing them to
  web search, causing test failures.

SOLUTION:
  Created HybridJudgeModule that analyzes claims for temporal indicators and
  routes to appropriate evaluation path:
    - Temporal/recent claims → FactCheckerPipeline (web search)
    - General knowledge → JudgeModule (fast LLM evaluation)

================================================================================
USAGE EXAMPLE
================================================================================

from src.factchecker.modules import HybridJudgeModule
import dspy

# Configure
dspy.configure(lm=dspy.LM("openai/gpt-4o-mini", api_key=api_key))

# Initialize
hybrid = HybridJudgeModule()

# Evaluate
result = hybrid(statement="In December 2025, Apple announced...")

# Output includes routing metadata:
print(result.routing_decision)   # "web_search" or "simple_judge"
print(result.routing_reasoning)  # Why that path was chosen
print(result.overall_verdict)    # SUPPORTED | CONTAINS_UNSUPPORTED_CLAIMS | ...
print(result.confidence)         # 0.0 to 1.0
print(result.reasoning)          # Detailed explanation

KEY INSIGHT
================================================================================

The optimizer now optimizes a SMARTER program that routes intelligently:

BEFORE: FactCheckerPipeline for everything
  • Temporal claims: OK but slow (web search needed)
  • General knowledge: Slow and wasteful (web search NOT needed)
  • Result: Inefficient, high cost, mixed accuracy

AFTER: HybridJudgeModule with intelligent routing
  • Temporal claims: Fast web verification (right tool for the job)
  • General knowledge: Lightning-fast LLM evaluation (right tool for the job)
  • Result: Efficient, low cost, high accuracy

GEPA can now learn WHEN to use each path, not just HOW to verify!
